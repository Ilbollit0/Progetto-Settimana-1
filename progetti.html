Pagina ricetta

Tecnologie: HTML5, CSS3, Git.

Una pagina web che presenta una ricetta di cucina. Esercizio di markup semantico applicato a un contenuto reale: titolo principale, sezioni distinte per ingredienti e procedura, lista ordinata per i passaggi, immagine del piatto finale con didascalia.

Cosa ho imparato: scegliere il tag giusto in base al significato del contenuto e non all'aspetto visivo. Differenza tra section e article. Uso di figure e figcaption per le immagini con didascalia.

Card di presentazione

Tecnologie: HTML5, CSS3.

Un biglietto digitale con nome, ruolo, foto profilo e link ai social. Esercizio su tag semantici, link esterni con target="_blank", immagini con alt significativo.

Cosa ho imparato: organizzare l'informazione in poco spazio mantenendo gerarchia visiva. Uso degli id per anchor interne. Pattern header / main / footer su una singola card.

Portfolio personale

Tecnologie: HTML5, CSS3, Google Fonts, Material Symbols, Git, GitHub Pages.

La pagina che stai vedendo. Costruita da zero in cinque giorni, partendo dal markup HTML e arrivando alla stilizzazione CSS completa con box model, pseudo-classi, pseudo-elementi e tipografia ragionata. Pubblicata online su GitHub Pages al termine della prima settimana di corso.

Cosa ho imparato: progettare una pagina pensando alla gerarchia dei contenuti prima del design. Stilizzare in modo consapevole partendo da un reset CSS. Gestire un repository Git con commit descrittivi. Pubblicare un sito statico online.
